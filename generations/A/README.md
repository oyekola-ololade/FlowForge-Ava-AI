# FlowForge AVA — Generation A

**Status:** HISTORICAL  
**Meaning:** original lead / appointment bot structure.

## What this generation represents

Generation A is the earliest recorded AVA build generation in the reconstructed project history. Its focus was the core lead-conversation and appointment-handling structure before later knowledge, tool and prompt refinements.

## Relationship to current AVA

The current system retains the same broad business problem—handle inbound leads, gather context and support booking/handoff—but later generations substantially expanded the knowledge/tool structure and refined prompts while preserving actual workflow behavior.

## Evidence boundary

This generation is a lineage record. The current repository does not claim that every node in the present workflow existed unchanged in Generation A.
